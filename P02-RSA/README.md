# Practica 02 - Algoritmo RSA

Solucion en Python para los valores `p = 67` y `q = 83`. El programa calcula
`n`, `phi(n)`, selecciona el cuarto candidato valido para `e`, obtiene el
inverso modular `d` y descifra los bloques proporcionados.

## Ejecutar

```bash
python3 rsa_practica.py
```

La implementacion usa solamente la biblioteca estandar de Python.
